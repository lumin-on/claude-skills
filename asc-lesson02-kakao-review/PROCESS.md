# ASC 2강 프로세스

목표: 카카오톡 내보내기 파일에서 안건별 상태를 판단하고 원문 근거로 검증한다.
실시간 수신·자동 답장·실제 개인정보·유료 API 신규 연결은 범위 밖이다.

1. 사람: 분석할 파일·기간 선택, 개인정보 제거, 공개 여부 결정.
2. Skill: 입력 파일 정리 및 줄 번호 부여.
3. Subagent(분석): 안건별 최신 상태·담당·기한·근거·모르는 점 반환.
4. Subagent(검토): 원문과 분석 결과를 대조, 채택/수정/보류 제안 및 누락 검토.
5. Skill(메인 Agent가 수행): 조율 규칙에 따라 두 결과 비교. 근거 충돌 시 분석 단계로 돌아가 재검토, 부족하면 사람에게 질문/보류. 최종 결정은 메인 Agent가 책임진다.
6. Skill: JSON·인용 검사 후 Markdown 보고서 작성.
7. 사람: 근거 원문 확인, 판단 보류 해소, 최종 사용·공개 승인.

실행은 순차이다. 검토자는 분석 결과를 입력으로 받으므로 두 작업을 무조건 병렬화하지 않는다.
사이트의 사람/Skill/Subagent 3종 분류에 맞춰 5단계는 '조율 절차 Skill'로 표시한다. 실제 판단 주체는 메인 Agent이며, Skill 자체가 자율 판단한다는 의미가 아니다.
