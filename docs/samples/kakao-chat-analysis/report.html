01한눈에 보기

  • 4명이 8/23(토) 북한산 정기 산행을 준비하는 열흘(8/3~8/12)의 대화. 39건, 하루 평균 6건 미만으로 조용하지만 잡담보다 실무 논의가 대부분이고, 세션은 대개 10~20분 안에 끝난다.
  • 닫힌 것 3건: 산행지·집결(북한산, 8/23 08:00 불광역 2번 출구 — 20분 만에 만장일치), 뒷풀이 예약(불광역 근처 막걸리집 15:00, 14명, 이수진 이름), 신입 환영은 뒷풀이 때 겸하고 자기소개 시간을 넣기로(진행 박준호).
  • 진행 중 2건: 단체티 견적은 김태현이 맡아 "이번 주 안에" → "수요일까지" → "내일 다시 재촉"으로 두 번 미뤄졌고 박준호가 두 번 재촉했다. 산행 준비물 공지는 이수진의 초안에 간식 항목이 더해진 단계로, 확정 공지는 아직이다.
  • 흐지부지 1건: 이수진의 회비 인상 제안(월 1만 → 1만5천, "반대 의견 있으면 말씀 주세요")은 열흘 동안 아무도 답하지 않았다. 뒷풀이 지원 재원을 위한 제안이었는데, 뒷풀이는 예약됐고 재원 문제는 그대로다.
  • 미정으로 남은 것: 신입 환영 준비물·선물("다음에 얘기하죠" 후 미개시), 단체티 사이즈 조사(최민아가 언급했지만 아무도 맡지 않음), 뒷풀이 인원 변동 최종 확인.
  • 역할 패턴: 박준호가 의제를 열고 사람을 지정하고 기한을 챙긴다. 이수진은 제안한 것을 같은 날 처리한다(예약 제안 → 5시간 반 뒤 완료). 최민아는 신입·분위기 쪽을 맡고 작은 보완을 더한다. 김태현은 아이디어를 내지만 실행이 늦다.
  • 산행 전 확인 포인트: 단체티 견적·주문(제작 기간을 감안하면 8/23까지 촉박), 준비물 최종 공지, 회비 인상 결론, 신입 선물 여부.

02화자와 역할

발화량보다 '무엇을 가져오고 누구에게 어떻게 반응하는가'로 읽은 역할.

박준호 운영 총괄 · 결정과 배정 (추정 회장)

11건 (28.2%) · 평균 27.9자 · 사진 0 · 링크 0 · 파일 0 · 주 활동 9시·8시·19시

의제를 열고 닫는 사람. 산행 후보 3곳을 던져 20분 만에 "그럼 북한산으로 정합니다"(#4)로 마무리했고, 단체티는 태현에게(#13), 뒷풀이 예약은 수진에게(#18) 바로 맡겼다. 기한도 챙긴다 — 견적을 8/10과 8/12 두 번 물었지만 "넵 천천히 하세요"(#31)로 압박은 누른다.

신입 자기소개 진행을 스스로 맡았고(#33), 준비물·선물 논의는 "다음에"로 미뤘다. 비 소식 같은 안부 인사(#10)도 이 사람이 한다.

이수진 실행 · 공지 담당 (추정 총무)

10건 (25.6%) · 평균 37자 · 사진 0 · 링크 1 · 파일 0 · 주 활동 12시·9시·22시

요청과 실행 사이 거리가 가장 짧다. 뒷풀이 장소를 지도 링크로 제안(12:31)하고 예약을 부탁받자 "오늘 전화해볼게요" → 같은 날 18:02 "예약했어요! 8/23 오후 3시 14명, 제 이름으로"(#20). 산행 준비물 공지 초안(#34)도 먼저 내고 민아의 간식 제안을 곧장 반영했다.

회비 1만 → 1만5천 인상(#9)은 이 사람이 낸 유일하게 답을 못 받은 제안이다. 다시 꺼내지도 않았다.

최민아 신입 · 분위기 담당, 보완 제안

10건 (25.6%) · 평균 21.8자 · 사진 1 · 링크 0 · 파일 0 · 주 활동 13시·10시·9시

사람 쪽 의제를 가져온다. 신입 두 명의 환영회 방식을 물었고(#23) "제가 두 분한테 따로 물어볼게요"(#25) 뒤 이틀 만에 의견을 전달했다(#32). 다른 사람의 계획에 한 줄씩 보완을 더한다 — 단체티에 "사이즈 조사도"(#15), 준비물에 "간식 나눠먹을 거"(#35).

도봉산 사진(#6)을 올리고 "수고했어요 👍"(#21)로 격려하는 등 방의 온도를 유지하는 역할. 산행지 투표에서는 "백운대 코스 가고 싶어요"(#2)로 유일하게 코스까지 말했다.

김태현 제안 · 단체티 견적 담당 (지연 중)

8건 (20.5%) · 평균 28.7자 · 사진 1 · 링크 0 · 파일 0 · 주 활동 21시·19시·9시

단체티 주문을 제안하고(#12) 견적을 맡았지만 "이번 주 안에"(#14, 8/4) → "수요일까지"(#30, 8/10) → "내일 다시 재촉해볼게요"(#38, 8/12)로 기한을 두 번 넘겼다. 매번 사과가 먼저 나오고, 이유는 두 번째 업체의 무응답이다.

산행지 투표에 "관악산은 여름에 너무 더워서"(#3)로 근거를 댔고, 혼자 다녀온 인왕산 야경 사진(#27)을 올리는 등 개인 산행이 잦다. 발언량은 가장 적지만(8건) 밤 시간대에 주로 나타난다.

8/3 09:12 박준호가 "이번 달 정기 산행 어디로 갈까요? 북한산 / 관악산 / 청계산"으로 투표를 열자 → 수진 "청계산은 저번에 갔으니 북한산" → 민아 "저도 북한산!! 백운대 코스 가고 싶어요" → 태현 "관악산은 여름에 너무 더워서 북한산 한 표" → 09:31 박준호 "그럼 북한산으로 정합니다 ㅎㅎ 날짜는 8/23 토요일 8시 불광역 2번 출구" → 수진 이모티콘으로 마무리.

결말 형식(뒷풀이 때 겸하기 + 자기소개 시간)과 진행자(박준호)가 정해짐(#33). 민아가 맡은 의견 청취는 이틀 만에 이행됐다. 다만 박준호가 "다음에"로 미룬 준비물·선물 논의는 8/12까지 열리지 않았다.

확인 포인트 신입 선물·준비물 논의가 실제로 열리는지. 8/23 뒷풀이에서 자기소개 시간이 진행되는지는 내보내기 이후.
